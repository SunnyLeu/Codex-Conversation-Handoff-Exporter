# Schema 輸出驗收資料

此資料為依稽核形狀製作的**合成案例**，不是私人 Session 原件，也不代表已完成全量真實資料驗收。識別碼、路徑、工具與文字均為測試用途。`data:image/png;base64,YQ==` 只測容器、解碼及雜湊，不宣稱解碼後是一張有效 PNG。

`source.jsonl` 是輸入；`expected-facts.json` 為獨立列出的值、型別及反向條件，不由匯出器的分類程式產生。Rust 測試核對讀取路徑及特殊邊界，Windows 腳本用真正編譯的 EXE 匯出後檢查這些事實。

既有七組續接與目的地安全驗收仍須通過，不能由本資料取代。


`real-case-derivatives.json` 另保存五個實際稽核 record 的**去識別化衍生樣本**：保留原生鍵、型別、動作列舉及缺欄形狀，替換私人文字／路徑／識別碼。附來源證據 hash 供專案內回查；衍生樣本不是原件 exact bytes，也不能宣稱覆蓋所有真實資料。

本批有 35 筆合成輸入、42 個 EXE 輸出預期事實；原生 user／assistant 正文也有正向要求，不能只靠「沒有不該出現的文字」通過。checker 本身檢查 null 與缺欄、陣列型別、大小寫、數字與字串差異，並要求錯誤版本值確實被拒絕。
